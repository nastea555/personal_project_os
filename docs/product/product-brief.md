# Product Brief — Personal Life Hub

Версия: 0.1 · Статус: черновик на ревью · Дата: 2026-10-27

## 1. Проблема

Личные задачи, расписание, заметки, привычки, вес и питание обычно разбросаны по нескольким приложениям. Ввод данных занимает время, поэтому их перестают вести. Расчёт калорий домашних блюд неудобен: нужен вес готового блюда, а не только ингредиентов.

## 2. Цель

Одно адаптивное веб-приложение (компьютер + телефон), где данные сохраняются в БД, а ввод ускоряется голосом. AI только предлагает структурированную запись — сохраняет всегда пользователь.

## 3. Пользователь

Один пользователь — владелец (v1). Использует приложение ежедневно с телефона (быстрый ввод) и с компьютера (просмотр, рецепты, планирование). Доступ с телефона по домашней сети — с Этапа 3, после отдельной спецификации с аутентификацией; на Этапах 1–2 приложение работает только на `localhost` (D-8, изменено 2026-11-05).

## 4. Модули и приоритет

| Модуль | Приоритет | Этап | Ключевая ценность |
|---|---|---|---|
| UI Shell + Dashboard (каркас) | Must | 1 | Навигация, дизайн-система, честные пустые состояния |
| Recipes & Nutrition | Must | 2 | Детерминированный расчёт ккал, дневник питания |
| Voice Inbox | Must | 3 | Голос → предпросмотр → подтверждение |
| Tasks & Calendar | Should | 4 | CRUD, расписание, поиск |
| Journal & Ideas | Should | 4 | Заметки, категории, поиск |
| Habits & Weight | Should | 5 | История, график веса |
| Dashboard (реальные данные) | Must | 5 | Обзор дня |

## 5. Принципы продукта

1. Решает реальные задачи, не демо-макет: никаких фиктивных графиков, фальшивых цифр, нерабочих кнопок.
2. Тёмная, минималистичная, технологичная тема.
3. Основные сценарии одинаково работают на компьютере и телефоне.
4. Данные хранятся в PostgreSQL и переживают перезагрузку.
5. AI не сохраняет данные сам; пользователь подтверждает или исправляет.
6. Расчёты, валидация и бизнес-правила — детерминированный код, не языковая модель.
7. У каждой функции есть проверяемые критерии приёмки и тесты.

## 6. Вне рамок v1

- Мультипользовательский режим, роли, совместный доступ.
- Медицинские рекомендации, диагнозы, советы по питанию.
- Нативные мобильные приложения (только адаптивный веб).
- Синхронизация с внешними календарями и фитнес-трекерами.
- Офлайн-режим.
- Светлая тема.

## 7. Метрики успеха (для владельца)

- Запись приёма пищи с телефона ≤ 30 с.
- Голосовая запись веса — от произнесения до сохранения ≤ 15 с.
- Ноль потерянных записей после перезагрузки/перезапуска сервера.

## 8. Открытые вопросы

- OQ-PB-1. Язык интерфейса: только русский? (Предположение: да, i18n вне рамок v1.) **Решено (D-7, 2026-11-02):** только русский.
- OQ-PB-2. Где будет работать приложение: только localhost или будет развёрнуто в сети? От этого зависит, нужна ли аутентификация в v1. **Решено (D-8, 2026-11-02; изменено 2026-11-05, F-UI-001 CL-01):** Этапы 1–2 — только localhost, без аутентификации; до Этапа 3 — доступ из домашней сети с аутентификацией (отдельная спецификация).
- OQ-PB-3. Единицы измерения фиксированы: кг, г, ккал? (Предположение: да.) **Решено (D-9, 2026-11-02):** кг, г, ккал.
