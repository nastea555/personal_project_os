# F-DEMO-002 — Отметка выполнения привычки

| Поле | Значение |
|---|---|
| ID | F-DEMO-002 |
| Версия | 0.3 |
| Статус | Draft |
| Изменения | 2026-11-02 — уточнены граница 7 дней и поведение при ошибке сохранения |

## 1. Назначение

Пользователь отмечает, выполнил ли он привычку в конкретный день, и снимает отметку, если ошибся.

## 2. Scope

**В рамках:** отметка и снятие отметки для одной привычки за сегодня и 6 предыдущих дней.

**Вне рамок:** создание и удаление привычек (F-HAB-001), статистика, напоминания, отметки старше 6 дней.

### Термины

| Термин | Значение |
|---|---|
| **Отметка** | Запись о том, что привычка выполнена в определённую календарную дату |
| **Сегодня** | Календарная дата по часовому поясу устройства пользователя |
| **Неделя привычки** | 7 дат: сегодня и 6 предыдущих календарных дней |
| **Переключатель «Выполнено»** | Элемент управления в строке даты; `role="switch"`, состояние в `aria-checked` |

## 3. Пользовательские сценарии

- **US-1.** Я отмечаю, что выполнил привычку сегодня.
- **US-2.** Я снимаю отметку, поставленную по ошибке.
- **US-3.** Я отмечаю вчерашний день, который забыл отметить.

## 4. Бизнес-правила

- **BR-1.** Для одной привычки на одну дату существует не более одной отметки.
- **BR-2.** Отметку можно поставить или снять только для дат недели привычки (сегодня и 6 предыдущих дней включительно).
- **BR-3.** Снятие отметки удаляет её; новая отметка той же даты создаёт её заново.

## 5. Критерии приёмки

| ID | Критерий |
|---|---|
| **AC-DEMO2-001** | Экран привычки показывает 7 строк — даты недели привычки, от сегодняшней (первая строка) к самой ранней (последняя). В каждой строке дата в формате «пн, 2 ноября» и переключатель «Выполнено». |
| **AC-DEMO2-002** | Если для даты нет отметки, нажатие на переключатель «Выполнено» переводит его в состояние `aria-checked="true"`; после перезагрузки страницы переключатель этой даты остаётся в состоянии `aria-checked="true"`. |
| **AC-DEMO2-003** | Если для даты есть отметка, нажатие на переключатель «Выполнено» переводит его в состояние `aria-checked="false"`; после перезагрузки страницы переключатель этой даты остаётся в состоянии `aria-checked="false"`. |
| **AC-DEMO2-004** | Если сервер вернул ошибку или не ответил за 5 секунд, переключатель возвращается в состояние до нажатия и показывается уведомление с текстом «Не удалось сохранить отметку. Попробуйте ещё раз.». |
| **AC-DEMO2-005** | Запрос на отметку или снятие отметки для даты вне недели привычки отклоняется с HTTP 422; набор отметок не меняется. |
| **AC-DEMO2-006** | Повторный запрос на отметку даты, у которой уже есть отметка, возвращает HTTP 200 и не создаёт вторую отметку: у привычки на эту дату по-прежнему одна отметка. |

## 6. Граничные случаи

| Случай | Ожидаемое поведение |
|---|---|
| Дата = сегодня − 6 дней | Входит в неделю привычки, отметка разрешена (AC-DEMO2-001, 002) |
| Дата = сегодня − 7 дней | Не показывается; запрос отклоняется с HTTP 422 (AC-DEMO2-005) |
| Дата = завтра | Не показывается; запрос отклоняется с HTTP 422 (AC-DEMO2-005) |

## 7. UI-состояния

| Элемент | Состояния |
|---|---|
| Переключатель «Выполнено» | выключен · включён · сохранение (нажатие заблокировано до ответа) |
| Уведомление об ошибке | скрыто · показано (AC-DEMO2-004) |

## 8. API-контракт

| Запрос | Успех | Ошибка |
|---|---|---|
| `PUT /api/v1/habits/{id}/marks/{date}` — поставить отметку | 200, тело `{"date":"2026-11-02","done":true}` | 422 — дата вне недели привычки; 404 — нет привычки |
| `DELETE /api/v1/habits/{id}/marks/{date}` — снять отметку | 204 | 422 — дата вне недели привычки; 404 — нет привычки |

Дата — `YYYY-MM-DD`; часовой пояс устройства передаётся в параметре `tz` (IANA, например `Europe/Moscow`). Модель данных: таблица отметок с уникальным ключом (привычка, дата) — BR-1.

## 10. Безопасность и производительность

Не применимо сверх общих правил проекта: один пользователь, только localhost (ADR-008); отдельных требований к производительности нет — запрос затрагивает одну запись.
