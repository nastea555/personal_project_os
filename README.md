# Personal Life Hub

Персональное веб-приложение для задач, расписания, заметок, привычек, веса и питания. Модульный монолит: React + TypeScript (frontend), Java 21 + Spring Boot (backend), PostgreSQL.

## Статус

| Этап | Состояние |
|---|---|
| 0 — Foundation | Документы созданы. Каркас frontend/backend, Docker Compose и CI — **не начаты**: ожидается решение по окружению (ADR-009) |
| 1 — UI Shell | Спецификация F-UI-001 v0.4 (ответы PO на §13) **на QA-ревью**. Код не написан |
| 2–5 | Не начаты |

Запускать пока нечего. Инструкции запуска появятся вместе с каркасом Этапа 0 и будут проверены фактическим запуском.

## Структура

```
docs/product/        product-brief.md — цели, модули, вне рамок
docs/architecture/   architecture-decisions.md — ADR
docs/qa/             test-strategy.md, traceability-matrix.md
specs/features/      спецификации функций (F-UI-001, ...)
specs/api/           контракты API
specs/data-models/   модели данных
frontend/            React + Vite (Этап 0)
backend/             Spring Boot + Maven (Этап 0)
tests/ui, tests/e2e  Playwright
```

## Роли (с 2026-11-02)

| Роль | Кто | Отвечает за |
|---|---|---|
| Product owner / аналитик | AI-агент | Требования, бизнес-правила, ответы на открытые вопросы — каждое решение с обоснованием в спецификации или ADR |
| Разработчик | AI-агент | Код, unit-тесты, сборка |
| QA-инженер | человек | Ревью требований и бизнес-правил, тест-дизайн, автотесты, QA-скиллы и QA-процесс, quality gates (готова ли спецификация к разработке, выполнен ли DoD) |

QA не принимает продуктовых решений, но может остановить переход к реализации или к следующему этапу, пока не закрыты замечания уровня High. Решения по окружению на компьютере (диски, установка программ, ADR-009) принимает владелец компьютера.

## Процесс

Spec (PO) → QA-ревью требований, AC и тест-кейсов → исправления PO → реализация небольшими изменениями → автотесты (реально запущенные) → ручная проверка → обновление матрицы трассируемости. Подробно — `docs/qa/test-strategy.md`. Ветки, pull requests, метки и QA gate — `CONTRIBUTING.md`.

## Конфигурация

Секреты только в `.env` (не коммитится). Шаблон — `.env.example`.
